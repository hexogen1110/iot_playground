Introduction to MQTT

MQTT (Message Queuing Telemetry Transport) is a lightweight and simple communication protocol widely used in IoT applications. It enables devices to communicate through small data packets, with a minimum control message size of just 2 bytes. This makes it efficient in terms of bandwidth and power usage. MQTT is highly reliable, scalable, and efficient, making it ideal for scenarios like IoT, instant messaging, and remote control.

MQTT Message Specification

In 1999, IBM introduced the first version of the MQTT protocol, designed with a “publish/subscribe” model to meet the needs of simplicity, intermittent connectivity, and lightweight transmission. Below are explanations of its publish/subscribe model, topic naming, and QoS (Quality of Service) settings.

Publish/Subscribe Model

MQTT uses a publish/subscribe model. A Publisher sends messages on a specific topic, and Subscribers receive these messages by subscribing to the topic. A Broker acts as the intermediary, forwarding messages from the Publisher to all Subscribers of that topic.

MQTT Topics

MQTT topics are UTF-8 encoded strings with unlimited levels (up to 65,535 bytes), separated by forward slashes /. Examples:

  • home/IoT1/temperature: Represents the temperature read by IoT device 1.
  • home/IoT2/humidity: Represents the humidity read by IoT device 2.

Quality of Service (QoS) Levels

MQTT defines three QoS levels:

  • QoS 0: At most once; no guarantee of successful delivery.
  • QoS 1: At least once; ensures delivery but may duplicate messages.
  • QoS 2: Exactly once; guarantees delivery with additional overhead.

These features make MQTT flexible and easily extensible for various scenarios.

Setting Up Mosquitto MQTT Broker on Raspberry Pi 3

Step 1: Update Package List

Run the following command: 

sudo apt-get update

Step 2: Install Mosquitto

Run the following command: 

sudo apt-get install -y mosquitto mosquitto-clients

Step 3: Configure Mosquitto

1. Get Raspberry Pi’s IP Address

Run the following command: 

hostname -I

2. Modify Configuration File

Run the following command: 

sudo vi /etc/mosquitto/mosquitto.conf

Edit the file to allow anonymous access and set the MQTT broker’s IP: 

allow_anonymous true  
listener 1883 [IP]

3. Restart Mosquitto

Run the following commands: 

sudo service mosquitto stop  
sudo service mosquitto start

Now the MQTT broker is active.

Results

mosquitto_sub -h [IP] -t [topic]
